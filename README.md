# ElMex Ops

Current production source: **v1.9.13**

This repository is the source copy for the ElMex Ops manager app.

## v1.9.13 changes
- Adds a saved, supplier-specific Shopping List Order that is independent from Inventory order.
- Shopping List rows and shared/copied supplier lists follow each supplier's saved store-walking route.
- Adds Arrange controls in Shopping List and Settings, with drag and ↑/↓ reordering on mobile.
- Refines the compact ElMex Ops branding to more closely match the approved mockup while preserving the sombrero and five gold stars.
- Keeps v1.9.12 features including shopping quantity overrides, Move Store, Quick Supplier Order, and insert-after-current inventory item behavior.
